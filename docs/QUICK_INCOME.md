# Quick income playbook

For JustTech users who need cash **this week**, not next quarter. Pair this
list with the app’s **fast-pay scoring** (higher pay, lean applications,
contract/temp tags ranked up).

## Today (hours, not days)

1. **Collect what’s already owed** — Send polite “invoice / payment status”
   nudges for every open client invoice, freelance payout, tax refund, or
   reimbursement. Fastest money is money already earned.
2. **List what you can sell or rent today** — Gear, unused licenses, a spare
   desk, short-term consulting hours. Prefer local pickup or instant payout
   rails (bank, PayPal, Stripe Instant).
3. **Same-week paid work platforms** — Apply only to roles that pay on
   delivery or weekly: Upwork (Hourly Protection + available-now), Toptal /
   Gun.io style screens if you’re already vetted, Contra, Braintrust,
   Wellfound “contract”, RemoteOK contract tags. In JustTech, keep a profile
   with `preferences.min_salary` set to your floor and
   `prefer_contract: true` so contract/temp postings score higher.
4. **Offer a fixed-scope sprint** — Message 5–10 past coworkers or clients:
   “48-hour paid spike: [bugfix / landing page / API glue / automation].
   Flat $X, invoice on delivery.” Concrete scope closes faster than “open
   to work.”
5. **Local / near-cash** — Day labor apps, tutoring (CS / coding interview),
   weekend IT help, event tech. Cash or same-day Zelle beats a 30-day W-2
   cycle when the goal is survival.

## This week (pipeline)

1. **Wire JustTech ingestion** — Enable RemoteOK + any RSS boards you trust;
   set profile skills honestly; set `min_salary` / `min_award` high enough that
   lowball roles drop. Run ingestion, then work the **Qualified** column
   top-down (board sorts by score, then pay).
2. **Apply only to lean postings** — Prefer cards tagged **fast apply**
   (few docs / questions) and **contract**. Draft in JustTech, human-approve
   fill, submit yourself the same day.
3. **Grants are usually slow cash** — Use grants for medium-term runway, not
   rent-due-Friday. If you chase awards, prioritize small local / foundation
   cycles with simple applications over multi-month federal packages.
4. **One paid pilot > ten applications** — Convert any warm lead into a
   written SOW: deliverable, price, date, payment terms (50% up front when
   possible).

## Profile prefs that help fast-pay ranking

Store under the applicant profile `preferences` JSON:

| Key | Effect |
|-----|--------|
| `min_salary` | Jobs below this get crushed in compensation score |
| `min_award` | Same for grants |
| `prefer_contract` | Boosts contract / temp / freelance / hourly tags |

## What not to waste time on

- Unpaid “equity only” or speculative content mills
- Roles with 6+ document packets when you need money this week
- Anything that requires relocation before first paycheck
- “Guaranteed income” schemes, fake gigs, or advance-fee scams

## After the fire drill

Keep the JustTech board as your ongoing funnel: ingest daily, clear
**Missing Information**, approve dry-runs, and treat **Follow-up** as money
you already invested effort in — chase those before new cold applies.
